# キャラクターと装備の台帳

「こう変えたい」「ここはどうなってたっけ」に、いつでも答えられるようにするための台帳。
**日本語名と英語名を必ず対で持つ。**

| ファイル | 中身 | 1行の意味 |
|---|---|---|
| `キャラクター.csv` | 全55体（実装済26＋次段19＋構想10） | ひとつの姿（騎士と聖騎士は別の行） |
| `装備分類.csv` | 装備の種類 15 | 剣・短剣…霊核 |
| `装備可否.csv` | 誰がどの種類を持てるか | ひとつの系譜 |
| `装備品目.csv` | 分類の下の実際の品 16 | ひとつの品（鉄の剣、革の胴…） |
| `用語.csv` | 理・系統・体格・段・属性・役割・状態の日英 | ひとつの言葉 |

装備は二階建て。**分類**（誰が持てるかを決める）→ **品目**（宝箱から出る実物）。

記号は `○` 持てる ／ `－` 持てない。

```
node tools/dbcheck.js   台帳とゲームのズレを並べる。台帳を直したら必ず走らせる
node tools/dbgen.js     台帳を engine.js から組み直す（作り直したいときだけ）
```

## 決めごと（2026-08-29）

- **体格** … 幼竜=中／竜=大／古代竜=大。人狼=小、ヴァルキリー=小、ゴーレム=中（ゲーム側も直した）
- **精霊の上の段** … フェニックス・ヨトゥンは二の段のまま（一→二の二段構成）
- **呪術師系** … 系統は邪悪系、理は秩序 Order。**系統と理は別の軸**
- **ヴァルキリー系** … 出自は神獣のまま。獣の皮を外し、軽鎧を持てるようにした。
  「装備できる＝実体がある」という線引きを保つため
- **神獣系は二つの意味を兼ねる** … 出自としての神獣（ヴァルキリー・オーディン）と、
  極まって神に届いた者（フェニックス・ヨトゥン・ブラギ）。
  **出自＝種族**（装備を決める）と**系統＝ルールの束**（復活を持つ）は別扱い
- **オーク・トロール・人狼・ハーピー・槍兵** … 段を持たない単体
- **槍術士・竜殺し** … 構想のまま
- **ゴーレム** … 大槌だけ。防具も装身具も持たない
- **鉤爪** … 道具屋や迷宮で手に入るふつうの装備。カテゴリ名が「鉤爪」なだけ
- **騎士は剣・短剣・槍／槍兵は槍だけ** … 意図どおり
- **吟遊詩人の武器は楽器だけ** … 意図どおり
- **吟遊詩人の三の段はブラギ**（元の表の「戦鬼」は戦士系との重なり。誤りとして直した）

## まだ決めていないこと

- **分類の決まっていない品**（銅の環・力の指輪・俊足の靴）… 指輪と靴は
  印章／護符／霊核のどれにも入らない。分類を足すか、印章に寄せるか
- **品が1つも無い分類**（短剣・弓・槍・杖・鉤爪・楽器・ローブ・獣の皮・霊核）
- **武器種・防具種の実装**そのもの。いまのゲームは 武器／防具／装身具×2 の4枠だけ

## 絵の決めごと（2026-09-06）

- **頭身の目標は6.3（戦士の絵が基準）。指定には「5.5」と書く**。生成側は頼んだ数字より約1頭身高く描く（5便の実測）
- **段ばしごは「同じ者の成長」ではない**。上の段は別人でよい（ゲーム仕様も「条件を満たすと上位の者を得る」だけ）。誰であるかは台帳の一体ごとの設定に置き、共通指定には段らしさの出し方だけ書く
- **性別**：一体ごとに台帳で決める（人系は今のところ系譜で揃えているが、象徴的に変えてもよい）。**僧侶系は女性**（僧侶・高僧・聖者）。神獣系は途中で変わる（ヴァルキリー女→オーディン男）。
- **体の向き**：角度の数字ではなく「顔・肩・足に見えるもの」で指定する。向きは姿が要求するもので決め、段の見分けには使わない（見分けはカメラ・構えの高さ・重心の3軸）
- **精霊（一の段）は性別を持たせない**＝性別を示す特徴（胸のふくらみ・腰のくびれ・髪・唇）を描かない。体格の強さ（胸の厚み・腕の太さ）は禁止しない。精霊が神獣に上がった段（トールなど）は個別指定で性別を持ってよい
- **解像度**：1枚に2体（1体あたり768px）
- **三の段**は「光ではなく素材で上げる」。**頭上の光の輪（後光）は全段で描かない**
- マゼンタ背景で描かせて機械で抜く／縁の光は入れない／地面を描かない／露出禁止／武器は握る／ぼろぼろは狂戦士だけ
- 便は**系譜でまとめる**。参考画像は 吟遊詩人・大賢者・闇の刃
- **獣系の共通の印**：牙・爪・角のどれかが必ず体の輪郭の外に出ている。表面の素材は4体で全部違う（緑の皮膚／青灰の皮膚と苔／灰黒の毛皮／茶の羽根）
- **竜の翼**：二の段の竜は張りのある無傷の膜（最強の姿）。傷んだ翼は三の段の古代竜の表現に取っておく
- **竜の色は「炎の温度」で段を作る**：幼竜＝朱赤（不完全燃焼。煤で濁ったオレンジの炎）→ 竜＝白金（完全燃焼。火力の頂点、白い炎）→ 古代竜＝蒼黒（熱の極致。見えない炎、鱗の隙間から青い光）。
  黒は「闇」ではなく「熱」。邪悪系の淀んだ黒とは意味が違う
- **精霊の姿**：サラマンダー＝炎の蛇（中世の動物寓話集の姿。人型にしない）／フリム＝霧氷の結晶が寄り集まった顔のない小さな人型（上のヨトゥン＝霜の巨人と骨格をそろえる）。どちらも人の体の特徴を持たない
- **邪悪系の段は「骨の量」**：呪術師＝杖に骨の護符ひとつ／死霊術師＝頭蓋骨の杖と浮く骨の手／リッチ＝本人が骸骨。性別は呪術師・死霊術師＝男、リッチ＝無
- **段の文法**：一の段＝実用・道具を握り動く・飾りなし・光は手の中まで／二の段＝道具が特別になる・金はひとつ／三の段＝本人は動かず、周囲や不在で示す（浮く杖・影の刃・光の環・見えない炎）。後光は全段で禁止

## 第2世代の絵（2026-09-06、30体完了）
- 元シート：`art_src/v2/binNN[_vN].png`（マゼンタ背景・2体シート。1体だけの縦長もあり）。採用版は台帳の「所見」に記載
- 切り抜き：`art/cut/<id>.png`（RGBA。768×1024以上、等倍。透明画素の色は灰120）
- 抜きの道具：`tools/keyout.py`（マゼンタ距離でアルファ／半透明の無彩色は透明度に／赤紫かぶりを無彩色化／塊ごとに左右の所属判定）
- 確認：`tools/layermock.py`（地(D案)→段の枠→切り抜き→縁の光 の重ね順で実寸に置く）、`docs/全30体_盤面136.png`・`図鑑352.png`
- 便の生成：`tools/bingen.py` → `docs/便/`。姿・注意は台帳 `絵の指定.csv` から
- 学び：三の段は「静」と書くと細長くなる→頭身は数値で（枠1024で頭170）／「両目が見える」は半分程度しか効かない／「前の絵を見本に姿勢を戻す」が最も確実／
  翼・剣先が枠をまたぐことがある（塊判定で拾える）／半透明の煙・光はマゼンタと混ざって上がる（抜きで透明度として拾う）
- 盤面の切り出し：`art/board_view.json`（top＝膝上から上を1.45倍／big＝全身のまま1.2倍）。数字は `src/style.css` の v95 の項
- 背景色：`art/bg_colours.json`（`tools/cut2webp.py` が系譜の色から作る。直すならそこ）
