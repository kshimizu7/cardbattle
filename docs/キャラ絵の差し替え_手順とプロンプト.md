## ① 退避 ── 三重に残してあります

**1. いまの線画の一覧画像**（新規）
`docs/線画_全45体.png` … 45体すべてを名前・id・状態つきで並べた控え。
何を捨てて何に変えたのか、後から必ず見比べたくなるので作りました。

**2. 元のコード**
`src/art.js` は**そのまま残します**。消しません。

**3. 差し替えは一体ずつでよい仕組みにします**
新しい絵を読むとき、**その id の画像が無ければ、自動で今の線画に落ちる**ようにします。
つまり26体のうち5体だけ差し替えた状態でも破綻しません。全部そろうまで待つ必要がない。

> **先に知っておいてほしいこと。**
> いまの線画は、戦闘中に**武器だけが振られる**動きを持っています（`.p-wep` を回している）。
> 絵を画像に差し替えると、この動きは失われます。代わりに「体ごと前に踏み込む」「一瞬明るく光る」
> といった演出に置き換えることになります。**戦闘の見た目はけっこう変わります。**

## ③ サイズと構図 ── なぜこの指定なのか

実際の画面を測りました。

| 使われる場所 | 表示サイズ | 端末の実ピクセル（DPR3） |
|---|---|---|
| 図鑑の一覧カード | 83 × 83（正方形） | 249 |
| **図鑑の詳細カード** | **352 × 303**（横長 1:0.86） | **1056 × 909** |
| 戦闘盤のユニット | 約 135 × 122 | 約 405 |

三つとも**縦横比が違い、すべて中央を切り出して**使っています。だから —

- **1024 × 1024 の正方形**で作る（いちばん大きい用途 1056px にほぼ合う）
- **人物は中央**に置き、左右にはみ出さない
- **頭の上に約12%、あごの下に約8%の余白**（横長に切ったとき頭が切れないため）
- **胸から上のバストアップ**

> **バストアップにする理由。** 戦闘盤のユニットは 135px しかありません。
> 全身像だと顔が 20px 程度になって誰だか分からない。バストアップなら顔が 60px 取れます。
> ただし**戦闘盤の見た目は「立ち姿」から「肖像」に変わります**。ここは好みが分かれるので、
> 第一陣の1〜2体を作った時点で、実機に貼って見比べましょう。

## ④ ChatGPT に渡すプロンプト

### 使い方

- **同じチャットの中で続けて生成する。** 画風がそろいます。チャットを分けると絵柄がぶれます
- **1体ずつ**作る。まとめて頼むと1体あたりの密度が落ちます
- **1体目を「基準」にする。** 2体目からは共通指定に加えて
  「1枚目と同じ画風・同じ光の当て方で」と一文足すと、さらにそろいます
- 気に入らないときは共通指定を貼り直さず、「**今のまま、〜だけ変えて**」と言う

### 【共通指定】── 毎回そのまま貼る

```
ダークファンタジーのカードゲーム用の、キャラクター肖像を1枚描いてください。

■ 画風
・重厚な油彩（デジタルペインティング）。写実寄りだが、筆の跡を残す
・彩度は低め。くすんだ灰緑・鈍色・革の茶を基調にし、金属と装飾だけが鈍く光る
・明暗のコントラストは強め。逆光ぎみ、または斜め上からの側光で輪郭を浮かせる
・アニメ調、セル塗り、カートゥーン調、3DCG調にはしない
・文字、ロゴ、枠線、署名、透かしは一切入れない

■ 構図（重要）
・正方形 1024×1024
・胸から上のバストアップ。顔がはっきり読めること
・頭の上に画面の約12%、あごの下から画面下端まで約8%の余白をとる
・人物は画面中央。左右にはみ出さない
　（※このあと中央を縦横それぞれ切り出して使うため）
・目線はこちら、またはやや斜め
・武器や持ち物は、肩口や胸元に見える範囲だけでよい。全体を写す必要はない

■ 背景
・無地に近い暗い背景。上がやや明るく、下へ暗く落ちるグラデーション
・指定の色を薄くにじませる程度。風景・模様・小物・地面は描かない
・人物の輪郭が、背景からはっきり分離していること

■ 禁止
・現代的なもの（眼鏡、腕時計、ロゴ入りの服など）
・実在の人物に似せること
・過度な露出
```

## ⑤ 受け取りかた ── ファイル名と置き場所

### ファイル名

**`<id>.png`**（半角英字そのまま、拡張子は png）

```
knight.png    warrior.png    spearman.png    shieldguard.png
archer.png    rogue.png      mage.png        priest.png
ogre.png      harpy.png      werewolf.png    golem.png
```

日本語名にしないでください。文字化けと表記ゆれで確実に事故ります。
ChatGPT は好きな名前で保存できるので、**ダウンロードするときに手で付け替える**のが確実です。

### 置き場所

```
C:\Users\kazu_\projects\cardbattle\art_src\
```

このフォルダに放り込んでおいてください。私が拾って、以下を自動でやります。

1. 1024px の PNG → **768px の WebP** に変換（1体あたり 40〜50KB になります）
2. `art/char/<id>.webp` に配置
3. `build.js` が自動で拾って埋め込む
4. 画像が無い id は、今の線画のまま

### ファイルの大きさについて

いまのゲーム本体は 1.0MB。26体ぶんの絵を足すと **約 2.2MB** になります。
スマホで開くには問題ない範囲ですが、気になるようなら
「図鑑の詳細だけ高解像度、カードと盤面は小さい絵」の二本立てにして減らせます。
**まずは 768px 一本で作って、実機で見てから決めましょう。**
