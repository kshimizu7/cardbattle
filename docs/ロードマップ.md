# 開発環境をいつ移すか ─ ロードマップ

やりたいこと3つに対して、**どこで環境を移すのが自然か**をまとめます。

結論だけ先に：

| 段階 | 時期 | 環境 |
|---|---|---|
| **① セーブ機能** | 近いうち | 今のまま＋**GitHubだけ足す**（ターミナル不要） |
| **② 近くの人と対戦（コード交換方式）** | ①の次 | 同上 |
| **② 本格オンライン対戦** | その先 | **ここでClaude Code＋GitHubへ移行** |
| **③ アプリストア** | もっと先 | 移行済みが前提 |

---

## ① 対戦履歴などのセーブ

### 技術的にできること

ブラウザの `localStorage` に保存すれば、単一HTMLのままセーブできます。移行は不要です。

### ただし落とし穴が1つ

**ファイルをそのまま開く（`file://`）と、端末によってセーブが消えます。**

- PCのChromeでファイルを開く → だいたい動く
- **iPhoneでメールやDriveから開く → 保存されない**

つまり「HTMLファイルを送って遊んでもらう」形のままだと、セーブは信用できません。

### 解決策：Webに置く

`https://` のURLで開く形にすれば、セーブは確実に動きます。おまけに、

- **URLを送るだけで友達が遊べる**（ファイル添付が要らない）
- 更新すると**全員が自動で最新版**になる
- スマホの**ホーム画面に追加**できる（アプリっぽくなる＝③への足がかり）

置き場所は **GitHub Pages が無料**で、いちばん素直です。

### だから「①のタイミングでGitHubを作る」のがお勧め

ここが大事なところですが、**GitHubを作るのにターミナルは要りません。**
このセッションからGitHubに直接つなげることを確認済みなので、

- kazuさんがやること：GitHubのアカウントを作る（無料）
- 私がやること：リポジトリ作成、ソース投入、GitHub Pages公開、以降の更新

で回せます。**Claude Codeへの移行はまだ不要**です。

### セーブの中身の案

- 対戦履歴（日時・使った編成・勝敗・決め手）
- 通算成績、キャラ別の勝率
- 「よく使う編成」の保存
- 保険として、**セーブデータを文字列で書き出し／読み込み**する機能も付ける
  （端末を変えても引き継げる）

## ② 近くの人・オンラインで対戦

ここは**2種類に分けて考える**とスッキリします。

### まず正直な話：Bluetoothはブラウザでは無理です

- **iPhoneのSafariはWeb Bluetoothに対応していません**（今後も対応予定なし）
- Androidでも、ブラウザ同士を直接つなぐ用途には作られていません

**「近くの人とBluetoothで対戦」は、③のアプリ化とセット**になります。
（アプリ化すれば iOS の Multipeer Connectivity / Android の Nearby が使えて、本当に近距離対戦ができます）

### 先に作れるもの：**編成コード交換方式**（サーバー不要）

これは**今の環境のまま、単一HTMLで作れます**。しかもかなり面白いはずです。

1. 自分の編成を短いコード（またはQRコード）にする
2. LINEなどで相手に送る／その場で見せる
3. 相手も自分の編成コードを返す
4. **双方の端末で、まったく同じ戦闘が再生される**

いまのエンジンは乱数の種（seed）を外から渡せる作りになっているので、
**同じ編成＋同じ種なら、どの端末でも1ダメージまで同じ結果**になります。素直に実装できます。

メリット：

- サーバー代ゼロ、通信の失敗もゼロ
- 離れていても、同じ部屋でも、同じやり方で遊べる
- 相手を待たなくていい（非同期）

「近くの人と対戦」の8割はこれで満たせると思います。

### 本格オンライン対戦（マッチング・レート・戦績サーバー保存）

こちらは**サーバーが必要**です。ここで前提が変わります。

- HTMLファイル1つ、では表現できない（サーバー側のコードが増える）
- 「公開中のバージョン」と「開発中のバージョン」を分ける必要が出る
- パスワードやキーの管理が発生する

**＝ここがClaude Code＋GitHubへの移行ラインです。**

## ③ App Store / Google Play

- 今のHTMLを **Capacitor** で包めば、そのままアプリとして出せます（作り直し不要）
- 費用：Apple **年 $99** ／ Google **初回 $25**
- 審査があるので「今ストアに出ている版」を正確に再現できる必要がある → **git必須**
- ここで初めて Bluetooth・近距離通信・プッシュ通知などが使えるようになります

## 移行タイミングのおすすめ

### 🔵 いま〜①・②コード交換まで … 今の環境のまま

単一HTMLの強みを使い切るフェーズです。
ファイル1つで完結、オフラインで動く、誰にでも送れる。この身軽さは資産なので、
必要になるまで手放さないほうがいいです。

**①に着手するときに、GitHubだけ足す。**（ターミナル不要／私が代行）

### 🟡 ②の本格オンライン対戦に着手する直前 … Claude Codeへ移行

移るなら**機能の切れ目**で移ってください。作りかけの途中で環境を変えるのがいちばん事故ります。

そのとき必要になるもの：

- ターミナルを使う（コマンドを打つ場面が出ます）
- Node と Playwright のインストール
- 代わりに手に入るもの：**本物の変更履歴、差分表示、巻き戻し、ブランチ**

### 🟢 ③ … 移行済みが前提
