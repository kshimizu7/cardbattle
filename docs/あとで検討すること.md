## 息づかい（呼吸）── 実装済みの先

**v80 で入れたのは2つだけ。**

- HPで呼吸が変わる（満タン=静か／55%以下=少し荒く／25%以下=速く深く／倒れたら止まる）
- 無生物系（ゴーレム・古代兵・古代巨神）は息をしない

**まだ入れていない案。**

- **次に行動する者が、一段深く息を吸う** … 行動順バーを見なくても、次に誰が動くか分かる。実用性が高い
- **状態異常で呼吸が変わる** … 燃焼＝小刻みに震える／鈍足＝周期が伸びる／呪い＝リズムが乱れる。
  属性のエフェクトを重ねなくても状態が伝わる
- **回復したとき、一度だけ大きく吸う** … 繰り返しではなく単発。数字が飛ぶのと同時に体が膨らむ
- **狙われているキャラの呼吸が速くなる** … 敵が対象を選んだ瞬間、その一体だけ息が速くなる
- **無生物は、たまに関節が軋むように微かに揺れる** … 息の代わり。「回復が効かない」設定と噛み合う
- **戦闘外（編成・図鑑）でも呼吸させる** … 生きて見えるが、情報は増えないので優先度は低い

## 攻撃の演出 ── 個別に詰める

**5つの型は決まった**（技の性質から自動で選ぶ）。

| 技の性質 | 出かた |
|---|---|
| 物理 × 正面・貫通 | 横から滑り込み、止まらずに抜ける |
| 魔法 × 単体・列 | 暗がりから浮かび、光を溜めてから放つ |
| 物理 × 列・範囲・全体 | 上から落ち、潰れ、もう一度跳ねる |
| 待機2回以上の大技 | 中央で震えながら溜め、集中線が外へ抜ける |
| 必中・狙撃 | 静かに寄り、絞られ、一閃で消える |
| 回復・支援 | 光の中から現れる（未作成） |

**個別に詰めるもの。**

- **弓の攻撃を作り直す** … 中央に出したあと、**一瞬だけ画像を少し小さくして**（引き絞る）、
  その状態で溜め、**技名と同時に拡大して「放つ」**。いまの試作は「絞られて消える」だけなので、
  矢を放った感じが足りない
- **退場のパターン**を作って、登場との組み合わせを見る（砕けて散る／闇に沈む／光に溶ける／横へ抜ける）
- **滞在中の効果**（斬撃・炎・光の柱）を、いまある属性エフェクトから流用できないか
- **カードの裏面の絵** … 「カード返し」の演出に要る。いまは仮の縞模様
- **回復・支援の型**（光の中から）をまだ作っていない

**後回しと決めたもの。**

- **どの技で演出を出すか**の線引き（大技だけ／全部／設定で切替）── 当面は**毎回表示**でよい
- **速さの調整と、演出を切る設定**
- **早送り中は演出を飛ばす**（自動再生とテンポの問題）
- **盤面が隠れる問題** … 自陣側だけに出す方針だが、横持ちでは自陣が画面の左半分なので、置き場所が変わる
