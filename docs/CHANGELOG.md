# ARCANA CLASH ─ 変更履歴

版番号はタイトル画面の下部に `ver ○○` として表示されます。

## v24 — 2026-08-22

**卓上対面モードを CPU戦でも使えるようにした**

v23 では「ふたり対戦のみ」に限定していたが、**ひとりで机に置いて見え方を確かめられない**
のが不便だった。文字サイズ・視野角・回し方の確認は相手がいなくてもできるので、制限を外した。

- CPU戦でも卓上対面モードが有効になる
- ⚙表示メニューでも、対戦モードを問わずトグルが出るようにした
- タイトル画面で卓上モードをONにすると、その下に**「相手側の回し方」の切替**が出るようにした
  （これまでは戦闘中の⚙表示からしか変えられなかった）

## v23 — 2026-08-22（検証版）

**コンパクト表示と卓上対面モード**

### 📐 コンパクト表示

行動順バーと戦闘ログを畳み、盤面と文字に回します。**卓上モードと関係なく、通常プレイでも効きます。**

測った結果、これまで**戦闘画面はどの端末でも画面に収まっていませんでした**（iPhone 890px/844px、
小型Android 874px/780px）。手に持つ分にはスクロールで済みますが、机に平置きすると誰もスクロールできません。

| 端末 | 修正前 | コンパクトON |
|---|---|---|
| iPhone 390×844 | 890px（46px超過） | **844px ✓** |
| 小型Android 360×780 | 874px（94px超過） | **780px ✓** |
| iPad縦 768×1024 | 1046px（22px超過） | **1024px ✓** |

隠れた機能（行動順・ログ・音・速度）はヘッダーの **⚙表示** から呼べます。

### ⇅ 卓上対面モード（ふたり対戦のみ）

机に端末を置いて向かい合って遊ぶための表示。

- **相手側のカードが相手を向きます**
- **操作パネルが、行動しているプレイヤーの手元へ移動して向きを変えます**
  （P2の番なら画面上端に出る）
- 攻撃対象の吹き出し（タップ／-6 など）は、つねに**選んでいる人**を向きます
- 卓上は視距離が伸びるので、文字を一段大きくしています

**回し方を2通り用意しました**（⚙表示 →「相手側の回し方」で切替）。実機で見比べてください。

- **カードごと回す** … 本物のボードゲームで自分のカードが自分を向くのと同じ
- **文字だけ回す** … キャラの絵は常に正立のまま、名前と数字だけ相手を向く

### 端末サイズに応じた文字拡大

これまで**端末が変わっても文字は11pxのまま**で、iPadでは1マス149pxに対して名前11pxという
スカスカな状態でした。画面幅に応じて拡大するようにしています（iPadでは名前17px）。

## v22 — 2026-08-22

**ふたり対戦の陣営ラベルを修正**

盤面は「side1が上・side0が下」で固定されており、行動順バーの凡例と交戦ラインのラベルが
side0 基準でハードコードされていました。そのため **P2 は、自分の軍が「敵軍」と表示された
画面でプレイしていました。**

- CPU戦：これまで通り「自軍／敵軍」「▲敵陣／▼自陣」（人間は必ず side0 なので正しい）
- ふたり対戦：**「プレイヤー1／プレイヤー2」「▲P2／▼P1」** に変更。1画面を共有するため、
  どちらから見ても正しい呼び名にした
- 行動順の詳細モーダル、ユニット長押しの詳細も同様に修正

## v21 — 2026-08-21

**セーブ機能（戦績・記録）**

- タイトル画面に **📊 戦績・記録** を追加。4つのタブ
  - **通算** … 勝率・勝敗数・全滅／判定の内訳・平均ラウンド・カードプール別成績
  - **履歴** … 直近60戦。タップすると**その試合の両陣営の編成**（誰が生き残ったか、与ダメ・撃破）が開く
  - **キャラ** … 自分が使ったキャラごとの使用回数・勝率・生存率・与ダメ・撃破（使用回数順）
  - **データ** … バックアップ、引き継ぎ、削除
- **設定を記憶**（音のON/OFF・戦闘速度・カードプール・配り方・対戦モード・CPUの強さ）
- **書き出し／読み込み** … `AC1:` で始まるコードで、別の端末や新しい版に記録を引き継げる
- 削除は**2回タップの確認**つき（誤操作で消えない）
- 編成画面の「自動整列」ボタンのIDが戦闘画面の「おまかせ」と重複していたので分離

### ⚠ 保存についての注意

**HTMLファイルを直接開くと、端末によっては記録が保存されません**（特にiPhoneでメールやDriveから開いた場合）。
ブラウザの仕様によるもので、`https://` のURLで開けば確実に保存されます。
保存できない環境では「データ」タブに警告が出るので、その場合は**書き出しコードを控えて**ください。

## v20 — 2026-08-21

**編成UIを刷新**

- 候補カードを**1タップ**すると前衛の左から順に配置される（12タップ → 6タップ）
- 次に埋まるマスに「次はここ」を表示
- 場のカードをタップすると**操作バー**が出る
  - `◀ 左へ` / `▼ 後衛へ`（`▲ 前衛へ`） / `右へ ▶`
  - `ℹ 詳細を見る` / `✕ 場から外す`
  - 隣が空いていれば移動、埋まっていれば**入れ替え**
  - バーを出したまま、空きマスや他のカードを**直接タップしてもOK**
- `⇅ 自動整列` … 近接を前衛・遠隔を後衛へ。前衛は体力順、後衛は素早さ順。
  近接が足りないときは**いちばん硬い遠隔キャラを前に出す**
- `↩ ひとつ戻す` … 配置・移動・整列・全消しまで遡って取り消せる
- マナを使い切ると、ヘッダーが金色＋出撃ボタンが光る
- 配置済みカードのタップが「削除」から「選択」になり、**誤タップで消えなくなった**
- 版番号をタイトル画面に表示するようにした
