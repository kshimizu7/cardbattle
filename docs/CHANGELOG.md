## v26 — 2026-08-22

**v25の不具合修正 ＋ 操作の簡略化**

### 🐞 決着後に画面が真っ黒になり、どこにも進めなくなる（重大）

横並びレイアウトのグリッド指定が結果画面にも残っていたため、
用意された領域名（ヘッダー／盤面／操作パネル）が存在せず、結果画面の中身が
置き場を失って消えていました。**タイトル・編成・受け渡し・結果の各画面で
横並び指定を必ず解除する**ようにしました。

### 🐞 画面が上下にちらつく（iPad mini / Edge）

v25で入れた「画面の向きが変わったら組み直す」処理が原因でした。
モバイルのブラウザは**アドレスバーが出入りするだけで resize が連発する**ため、
そのたびに画面を作り直して揺れていました。
**向きが実際に変わったときだけ**組み直すよう修正（さらに演出中は組み直さない）。

### 🐞 列攻撃（業火のブレスなど）の枠が1マス分しかない

範囲の枠を「左端のマスから右端のマスまで」で計算していたため、
**横持ちでは列が縦に並ぶ**のに高さが1マス分のままでした。
両端のマスから**縦横まとめて外接矩形**を取るよう修正。縦持ち・横持ちどちらでも
3マスを正しく囲みます。（対象キャラ3体のハイライト自体は元から正しく出ていました）

### ✋ 選ぶ必要がない技は、ボタンをもう一度押すだけで実行

大治癒（味方全体）のように**当たる相手が決まっている技**でも、
わざわざ盤面のマスをタップさせていました。**技ボタンの再タップで実行**できます。

対象：全体攻撃・全体回復・必中・薙ぎ払い・乱れ撃ち・防御など。
（1体を選ぶ技、範囲を選ぶ技はこれまでどおり選択が必要です）

### 🧹 毎回出る操作説明を抑制

「○体すべてに必ず命中」「光っているマスをタップして実行」「キャラを長押しすると詳細」の
うち、**操作の案内部分を数ターン後に自動で畳みます**（当たる体数だけ残る）。
技ボタン再タップで実行できるようになったため、案内自体が不要になりました。

### 📋 操作パネルに行動順を表示

横向き・パネル右置きのとき、余っていた縦のスペースに**行動順の一覧**を出します。
現在の手番がハイライトされ、行動済み・戦闘不能も分かります。

### ⛶ 全画面ボタン

ヘッダーに追加。ブラウザのアドレスバーを隠せます。
（対応していない端末では、ホーム画面に追加すると隠れます）

## v25 — 2026-08-22

**横並び対戦モード ／ 卓上対面モードの撤去**

### 🤝 横並び対戦

向かい合わず**隣に並んで座り、端末を横にして左右で戦う**モード。

対面配置（v23/v24）は行き詰まりました。**このゲームは毎ターン相手の数字を読まないと打てない**のに、
向かい合うと相手側が必ず逆さまになるためです。調べた既存アプリ（Two Player Chess Basic の対称駒、
Easy Chess 2P の二重盤、MTGライフカウンターの片側専用表示）は、どれも「相手側を読ませない」設計で
問題を**回避**していました。

横並びなら**画面の向きがひとつだけ**になり、逆さまの文字が一つも出ません。

```
┌────────────────────────────────────┐
│ P1 後衛│前衛 ‖ 前衛│後衛 P2        │
│   □    │  □  ‖  □  │  □           │
│   □    │  □  ‖  □  │  □           │
│   □    │  □  ‖  □  │  □           │
└────────────────────────────────────┘
  ↑左に座る人            ↑右に座る人
```

- **端末を横にすると自動で切り替わります**（縦に戻すと従来表示）
- 盤面の意味は不変。後衛が外側、前衛が内側（交戦ラインに接する）。
  近接の「正面」は同じ高さの敵で、左右一直線になるぶん縦積みより見やすい
- ゲームエンジンは変更なし。**表示だけの変更**

### 📍 操作パネルの位置を選べます

| 端末 | 下の帯 | 右サイド |
|---|---|---|
| iPad mini 横 | **264×192px** | 179×217px |
| iPhone 横 | 192×69px | **128×99px** |

**下の帯**は盤面が全幅を使えるためタブレットでマスが約1.3倍になり、隣に並んだとき
**どちらからも等距離**で届きます。**右サイド**は縦の余裕がない端末でもマスの形が崩れません。

既定は**自動**（画面の高さで判断）。設定で「下に出す」「右に出す」を明示できます。

### ⚔ 対戦開始画面

編成が済むと、**端末を横にするよう促す画面**が出ます。横向きになるとボタンが光ります。
縦のままでも開始できます（強制しません）。

編成は従来どおり**縦持ちで各自**が組みます（隣に座ると覗きやすいため、隠す仕組みは維持）。

### 撤去

- 卓上対面モード（v23/v24）を削除。役目を終えたため、設定項目を減らしました

## v23 — 2026-08-22（検証版）

**コンパクト表示と卓上対面モード**

### 📐 コンパクト表示

行動順バーと戦闘ログを畳み、盤面と文字に回します。**卓上モードと関係なく、通常プレイでも効きます。**

測った結果、これまで**戦闘画面はどの端末でも画面に収まっていませんでした**（iPhone 890px/844px、
小型Android 874px/780px）。手に持つ分にはスクロールで済みますが、机に平置きすると誰もスクロールできません。

| 端末 | 修正前 | コンパクトON |
|---|---|---|
| iPhone 390×844 | 890px（46px超過） | **844px ✓** |
| 小型Android 360×780 | 874px（94px超過） | **780px ✓** |
| iPad縦 768×1024 | 1046px（22px超過） | **1024px ✓** |

隠れた機能（行動順・ログ・音・速度）はヘッダーの **⚙表示** から呼べます。

### ⇅ 卓上対面モード（ふたり対戦のみ）

机に端末を置いて向かい合って遊ぶための表示。

- **相手側のカードが相手を向きます**
- **操作パネルが、行動しているプレイヤーの手元へ移動して向きを変えます**
  （P2の番なら画面上端に出る）
- 攻撃対象の吹き出し（タップ／-6 など）は、つねに**選んでいる人**を向きます
- 卓上は視距離が伸びるので、文字を一段大きくしています

**回し方を2通り用意しました**（⚙表示 →「相手側の回し方」で切替）。実機で見比べてください。

- **カードごと回す** … 本物のボードゲームで自分のカードが自分を向くのと同じ
- **文字だけ回す** … キャラの絵は常に正立のまま、名前と数字だけ相手を向く

### 端末サイズに応じた文字拡大

これまで**端末が変わっても文字は11pxのまま**で、iPadでは1マス149pxに対して名前11pxという
スカスカな状態でした。画面幅に応じて拡大するようにしています（iPadでは名前17px）。

## v21 — 2026-08-21

**セーブ機能（戦績・記録）**

- タイトル画面に **📊 戦績・記録** を追加。4つのタブ
  - **通算** … 勝率・勝敗数・全滅／判定の内訳・平均ラウンド・カードプール別成績
  - **履歴** … 直近60戦。タップすると**その試合の両陣営の編成**（誰が生き残ったか、与ダメ・撃破）が開く
  - **キャラ** … 自分が使ったキャラごとの使用回数・勝率・生存率・与ダメ・撃破（使用回数順）
  - **データ** … バックアップ、引き継ぎ、削除
- **設定を記憶**（音のON/OFF・戦闘速度・カードプール・配り方・対戦モード・CPUの強さ）
- **書き出し／読み込み** … `AC1:` で始まるコードで、別の端末や新しい版に記録を引き継げる
- 削除は**2回タップの確認**つき（誤操作で消えない）
- 編成画面の「自動整列」ボタンのIDが戦闘画面の「おまかせ」と重複していたので分離

### ⚠ 保存についての注意

**HTMLファイルを直接開くと、端末によっては記録が保存されません**（特にiPhoneでメールやDriveから開いた場合）。
ブラウザの仕様によるもので、`https://` のURLで開けば確実に保存されます。
保存できない環境では「データ」タブに警告が出るので、その場合は**書き出しコードを控えて**ください。
