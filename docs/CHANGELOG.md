# 変更履歴について

**変更履歴の正本は、リポジトリ直下の [変更履歴.md](../変更履歴.md) です。**

このファイルはかつて履歴を持っていましたが、v76 で更新が止まり、
`変更履歴.md` と二重管理になっていました。混乱を避けるため、案内だけを残しています。

- 版ごとの変更内容 … [../変更履歴.md](../変更履歴.md)
- いまの最優先タスクと未決定事項 … [現在地.md](現在地.md)
- 設計の理由 … [設計判断.md](設計判断.md)

版を切ったときは **`変更履歴.md` だけ**を日本語で更新してください。
このファイルには追記しません。
