## v73 — 2026-08-28

**宿の「装い」を作り直し／氷の精霊フリム／戦闘盤の不具合の修正**

- ⚔ **装いが、ひと画面で完結するようになりました。**ページはもう縦に動きません
  - **上に一行の顔ぶれ**（常に見えていて、押せばその場で切り替え。装備できる品がある者には金の点）
  - その下に**その者の合計**（攻・HP・速）と、**4つの枠を2×2**で
  - **枠を押すと、その枠に入る品だけが下に並びます。**探しに行く必要はありません
  - 品には**いまの装いとの差**（攻 +4／速 +1 など）が出ます。良い順に並びます
  - 押せば**その場で上の枠と合計が変わり**、合計が一瞬光ります
  - 付け替えると、外れた品は自動で荷に戻ります。呪われた枠は赤く、押せば呪いの内容と神殿の値段が出ます
- ❄ **氷の精霊がフリムになりました。**フリム（霜）→ ヨトゥン（霜の巨人）。
  希薄な姿なので体は**小**、狭い迷宮にも入れます
- 🦍 **イエティは、いったん休演です。**毛皮と体のある獣で、現象である他の精霊と並びが悪いためです。
  **カードのデータはそのまま残してあり**、`retired` の一語を外せばいつでも戻せます
  （図鑑・雇用・敵の顔ぶれからは外れています）
- 🐞 **迷宮の戦闘で盤面のキャラが表示されなくなっていた不具合を修正。**
  v69 で宿用に足した見た目の指定（`.cell` `.slot`）が、戦闘盤の同じ名前の枠にも当たっていました
  （キャラの枠が 2×2 ピクセルまで潰れていた）。宿の指定は宿の中だけに効くよう囲い直しました

- 🧭 組んだ隊列は、そのまま迷宮の一行になります（前衛・後衛の位置も、カードバトルにそのまま渡ります）
- 🎒 一行から外した仲間の装備は、その人が持ったまま。戻せば、そのまま身につけています

## v67 — 2026-08-27

**宝箱と装備（Phase 2c-1）── 拾って、身につけて、戦いに効く**

- 🧰 **宝箱を置きました。**置かれ方は二通り。**最奥の間**（主のいる部屋）には必ずひとつ、
  そして**道の行き止まりや関門の先**に、依頼とは関わりなく、ひっそりとひとつ。
  格は3段階（**宝箱／至宝／古代遺物**）。同じ依頼なら同じ場所にあり、**一度取れば二度と出ません**
- 🪤 **開け方を選べます。**「そのまま開ける」は早い。「まず調べる」は手間がかかり物音を呼ぶこともありますが、
  仕掛けの7割は見抜けます。**罠にかかっても中身は必ず手に入ります**（傷を負うだけ）
- ⚔ **装備は4枠**（武器・防具・装身具2つ）。効果は**カードバトルの数値にそのまま乗ります**
  ——攻撃・HP・素早さ。荷の「一行の装い」から、誰に持たせるかを決めます
- 🎲 **同じ品でも出来に幅があります。**「鉄の剣」も「鉄の剣＋2」もある。奥の箱ほど、良い等級と大きな＋値が出ます
- ❓ **拾った時点では正体が分かりません。**「刃物のような何か？」のまま。**身につけてはじめて**分かります
- 💀 **呪い。**稀に呪われた品が出ます。腕は立つのに、代償がある——
  **蝕む**（戦いのたび持ち主 -2）／**重い**（素早さ -3）／**貪る**（傷薬の効き半減）／**脆い**（HP -4）。
  身につけたら、その探索のあいだ**外せません**（街での解呪は次の段で）
- 🏠 **装備は街へ持ち帰れます。**次の探索にも、そのまま身につけて行けます。ただし**全滅すればすべて失います**
- 🗺 手つかずの宝箱は、地図に小さな箱の印で残ります
