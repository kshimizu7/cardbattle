# ARCANA CLASH ─ 変更履歴

版番号はタイトル画面の下部に `ver ○○` として表示されます。

---

## v21 — 2026-08-21

**セーブ機能（戦績・記録）**

- タイトル画面に **📊 戦績・記録** を追加。4つのタブ
  - **通算** … 勝率・勝敗数・全滅／判定の内訳・平均ラウンド・カードプール別成績
  - **履歴** … 直近60戦。タップすると**その試合の両陣営の編成**（誰が生き残ったか、与ダメ・撃破）が開く
  - **キャラ** … 自分が使ったキャラごとの使用回数・勝率・生存率・与ダメ・撃破（使用回数順）
  - **データ** … バックアップ、引き継ぎ、削除
- **設定を記憶**（音のON/OFF・戦闘速度・カードプール・配り方・対戦モード・CPUの強さ）
- **書き出し／読み込み** … `AC1:` で始まるコードで、別の端末や新しい版に記録を引き継げる
- 削除は**2回タップの確認**つき（誤操作で消えない）
- 編成画面の「自動整列」ボタンのIDが戦闘画面の「おまかせ」と重複していたので分離

### ⚠ 保存についての注意

**HTMLファイルを直接開くと、端末によっては記録が保存されません**（特にiPhoneでメールやDriveから開いた場合）。
ブラウザの仕様によるもので、`https://` のURLで開けば確実に保存されます。
保存できない環境では「データ」タブに警告が出るので、その場合は**書き出しコードを控えて**ください。

## v20 — 2026-08-21

**編成UIを刷新**

- 候補カードを**1タップ**すると前衛の左から順に配置される（12タップ → 6タップ）
- 次に埋まるマスに「次はここ」を表示
- 場のカードをタップすると**操作バー**が出る
  - `◀ 左へ` / `▼ 後衛へ`（`▲ 前衛へ`） / `右へ ▶`
  - `ℹ 詳細を見る` / `✕ 場から外す`
  - 隣が空いていれば移動、埋まっていれば**入れ替え**
  - バーを出したまま、空きマスや他のカードを**直接タップしてもOK**
- `⇅ 自動整列` … 近接を前衛・遠隔を後衛へ。前衛は体力順、後衛は素早さ順。
  近接が足りないときは**いちばん硬い遠隔キャラを前に出す**
- `↩ ひとつ戻す` … 配置・移動・整列・全消しまで遡って取り消せる
- マナを使い切ると、ヘッダーが金色＋出撃ボタンが光る
- 配置済みカードのタップが「削除」から「選択」になり、**誤タップで消えなくなった**
- 版番号をタイトル画面に表示するようにした

## v19 — 2026-08-21

**プレイモードを2種類に**

- 🎲 **シャッフルモード**（既定）… プールから無作為9枚。**敵味方まったく同じ9枚**
- 📚 **フルカードモード** … そのプールの全カードが候補
- 「フルセット」→「**エクステンション**」に改名（今後さらに増える拡張パックの位置づけ）
- 候補13枚以上のときは手札を4列表示に
- 候補が敵味方共通になったため、**マリガン（引き直し）を廃止**

## 開発メモ

- ソース：`src/` の7ファイル（engine / ai / save / sfx / art / ui ＋ style.css）合計 約7,200行
- ビルド：`CBVER=21 node build.js` → `ArcanaClash.html` と `dist/ArcanaClash_v21.html`
- 復元：`node recover.js <ArcanaClash.htmlのパス>` で `src/` を丸ごと復元できる
- テスト：`CBPOOL=full CBDEAL=shuffle node batch.js 3`（自動プレイ回帰）
