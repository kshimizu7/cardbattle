# キャラごとの角度とカメラ

2026-09-05 決定。生成のたびに迷わないよう、26体ぶんを先に決めた。

## 決め方の規則

**体の向き＝役割。** 正面を0度、真横を90度として、全員わずかにでも右を向く（完全な正対は作らない）。
敵の絵は盤面で左右反転するので、味方は右・敵は左を向き、二つの陣営に見える。

| 段階 | 度 | 使いどころ |
|---|---|---|
| 浅い斜め | 20 | 盾役・巨体。正対に近いが、わずかに振る |
| 斜め | 35 | 標準 |
| 半身 | 55 | 体の厚みが見える。奥の腕が半分隠れる |
| 真横 | 85 | 弓を引くなど、動作が要求するもの |
| 背中側 | 120 | 振り向きざま。26体で暗殺者ただ一枚 |

**カメラ＝そのキャラの性格。** 見下ろし／正面／見上げの3種。
角度は浅くてよい。判定の目印は「あごの下が見えるか」「足元の地面が見えるか」。

- **見下ろし** … 這う者、屈む者、まだ幼い者
- **正面** … 対等に向き合う者、実体を持たない者
- **見上げ** … 大きい者、飛ぶ者、格の高い者

内訳は 正面8・見下ろし6・見上げ12。

> **顔を見せたいキャラは正面、体の大きさを見せたいキャラは見上げ。** これが規則の芯。
> 強いあおりは顔を小さく上へ追いやるので、顔が命のキャラには使わない。

## 補足

- **盾役も、わずかに横を向ける**（浅い斜め20度）。完全な正対だと、横持ちの対峙から一体だけ浮いて見えるため
- **真横は弓兵だけ。** 真横は顔が半分になり、装備が片側しか見えず、武器が体に重なるので情報量が落ちる
- **背中側は暗殺者だけ。** 一枚だけだからこそ効く。増やすと単調になる
- 次の段（聖騎士王・大賢者など19体）は、元の姿と同じ向き・一段強いカメラを基本にする
